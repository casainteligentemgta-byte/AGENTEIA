# Cuestionario de validación — Flujo de importación (Puerto Libre)

**Producto:** SmartImport · planilla de importación vehicular  
**Objetivo:** Confirmar con ustedes que los **datos** y **documentos** solicitados en cada fase son los correctos para su operación, y recoger **funciones adicionales** que quieran priorizar.

| Campo | Completar |
|-------|-----------|
| Organización / cliente | |
| Persona de contacto | |
| Cargo / rol | |
| Correo / teléfono | |
| Fecha de revisión | |
| Régimen que usan de verdad | ☐ Puerto Libre · ☐ Equipaje · ☐ Ordinario · ☐ Diplomático · ☐ Temporal · ☐ Otro: _______ |

**Cómo responder**

- En cada ítem marque: **OK** (correcto) · **CAMBIAR** (nombre, momento o obligatoriedad) · **QUITAR** · **AGREGAR** (anote qué falta).
- Use la columna **Comentarios** para matices (ej. “solo en persona jurídica”, “lo pedimos después del pago”).
- Al final hay un bloque de **funciones adicionales** y una firma de conformidad.

## Resumen rápido del flujo actual

```
Cliente → Registro → Embarque → Llegada → Desaduanamiento SENIAT
       → Pago impuesto → Inspección → Propietario → Seguro
       → Matriculación INTT → Placa → Nacionalizar (M2/M3)
```

Cada unidad genera un expediente interno `PL-año.mes.N` (distinto del número que asigne SENIAT).
